# 17Assets

Asset library for Interesting Times (1N7ERES71NG 71MES, "17"). Private.

Managed by the `17-assets` Claude skill. `index.json` is the source of truth —
don't hand-edit it; let the skill's scripts write it.

## Structure

| Folder | Holds |
|---|---|
| `mode-a-editorial/` | Editorial Generated — hero stills + motion |
| `mode-b-process/` | Process / screen capture, build logs |
| `mode-c-documentary/` | Documentary MENA photography — credit required |
| `mode-d-surveillance/` | AI-vision overlays, green-locked |
| `mode-e-lofi-retro/` | Lo-fi retro / CRT / Y2K / pixel-Arabic |
| `mode-f-meme-poster/` | Meme-as-poster, B&W + calligraphy |
| `logos/` | wordmark, glyph, N°17 stamp variants |
| `stickers/` | gif stickers |
| `icons/` | icon sets |
| `_inbox/` | raw dumps awaiting classification |

Modes mirror the six imagery modes in the `17-visual` skill.
